M.S. Computer Science · Artificial Intelligence & Machine Learning

Deep learning computer-vision course: a four-part CNN project on the CIFAR-10 and CIFAR-10-C image datasets, framed as a new instructor designing a course project. Task 1: project introduction and architecture justification (image-classification use cases, industry applications, bias avoidance). Task 2: data cleaning in the Cloud Academy lab (noise/blur/occlusion handling, null-image removal, resolution clarification, padding strategy, train/validation/test splits) saved to GitLab. Task 3: neural-network build in Jupyter (model summary interpretation — parameters, layer types, output shapes; convolutional/pooling/dense layer design; hyperparameter tuning via grid/random/Bayesian search). Task 4: comprehensive evaluation — stopping criteria, loss/accuracy curves, confusion matrices, overfitting analysis, data augmentation effects, class-imbalance handling, error analysis, ethics, deployment and scalability.

M.S. Computer Science · Artificial Intelligence & Machine Learning

Advanced AI systems course integrating AI techniques with data engineering, delivered as two versioned mini-projects. Model 1: a multilayer CNN image classifier (TensorFlow/Keras) on CIFAR-10 (60k 32x32 RGB images) — three convolutional stages with ReLU and max-pooling, mini-batch gradient descent with Adam, holdout validation, and a deployability story via REST APIs/containers. Model 2: a probabilistic cyber-defensive spam classifier using Gaussian Naive Bayes (scikit-learn) with univariate SelectKBest feature reduction and stratified splits. Both models were benchmarked, optimized, and validated, with all work tracked in GitLab across a six-commit history.
